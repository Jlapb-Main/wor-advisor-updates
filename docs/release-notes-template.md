Самостоятельное локальное приложение для Windows 10/11 x64. Скачайте ZIP, распакуйте всю папку и запустите `WoR-Advisor.exe`. Python, Node.js, Electron и EmuManager не нужны. Данные хранятся отдельно в `%LOCALAPPDATA%\WoR Advisor`.

Работают аккаунты и ростер, исходный сканер с ручным подтверждением, 276 портретов, локальный OCR, каталог API с 295 подробными карточками, подбор Main/Sub и замен, совместный Gear Optimizer, собственные карты, Visual Battle Planner, направления/диапазоны/шаги/Cost, сравнение планов, история и резервные копии. Доступны JSON/CSV/PNG/PDF/ZIP и проверка обновлений.

Поддерживаются легендарные, эпические и редкие герои. Редкость не является рейтингом силы. Стартовые составы могут состоять целиком из эпиков; эпик с нужной механикой может быть предпочтительнее легендарного без неё. Выбор идёт по фактическому ростеру и наблюдаемым свойствам для режима.

В исходной базе нет проверенного полного атласа карт. 326 ориентиров являются исследовательской очередью. Для точной расстановки загрузите настоящий скриншот и подтвердите геометрию. Неизвестные механики и пробелы явно отмечаются. Ограниченный поиск не выдаётся за гарантированную победу или доказанный глобальный оптимум.

Сборка проверена тестами Windows/Linux и запуском сканера и OCR из готового EXE. Руководство и известные ограничения находятся внутри ZIP. Программа работает без постоянного интернета, не управляет игрой и не расходует ресурсы. Контрольная сумма SHA-256 опубликована рядом с архивом.
