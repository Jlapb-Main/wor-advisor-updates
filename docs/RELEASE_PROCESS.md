# Порядок публикации выпусков

Это описание будущего процесса; автоматическая сборка и доставка обновлений пока не настроены.

1. Реализовать изменения и выполнить необходимые проверки в репозитории `Jlapb-Main/wor-advisor`.
2. Собрать приложение на Windows и проверить запуск, работу без интернета и сохранность пользовательских данных.
3. Создать выпуск с тегом версии, указать полный SHA исходного коммита и описание изменений.
4. Прикрепить сборку и файл контрольных сумм SHA-256 к GitHub Release в этом репозитории.
5. После проверки доступности вложений обновить `channels/stable.json`, указав сведения о фактически опубликованном выпуске. До реализации и проверки формата обновления оставлять `release: null`.

База игровых данных и версия приложения имеют независимые версии. Обновление игровых данных не должно перезаписывать ростер, инвентарь, историю и пользовательские карты.
