# WoR Advisor — выпуски и обновления

Репозиторий предназначен для Windows-сборок WoR Advisor, журналов изменений и метаданных обновлений.

- [Исходники программы](https://github.com/Jlapb-Main/wor-advisor).
- [Выпуски](https://github.com/Jlapb-Main/wor-advisor-updates/releases).
- [Канал stable](channels/stable.json).
- [Порядок публикации](docs/RELEASE_PROCESS.md).

Сборки пока не опубликованы. Значение `release: null` в канале stable означает отсутствие доступного выпуска. Механизм обновления приложения ещё не реализован.

Репозиторий публичный: предназначен только для выпусков и метаданных обновлений. Исходный код и пользовательские данные здесь не размещаются.
